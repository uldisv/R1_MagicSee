# R1 Keeper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fona programma, kas Magicsee R1 pulti pēc katras parādīšanās klusi sapāro ar Windows no jauna un atgādina pārslēgt spēļu režīmu.

**Architecture:** Visa lēmumu loģika (kad noņemt pārošanu, kad pārot, atkārtojumi, pauze, piesaiste vienai adresei) dzīvo `R1Keeper.Core` bez Windows API un tiek pārbaudīta ar viltus Bluetooth. `R1Keeper` (WinForms paziņojumu joslas programma) dod īsto Bluetooth caur WinRT, lasa HID multivides kolekciju un rāda ikonu. Core neko neglabā par pārošanas stāvokli — to vienmēr prasa Bluetooth slānim.

**Tech Stack:** C#, .NET 10, `net10.0` (Core, testi) un `net10.0-windows10.0.19041.0` (programma), WinForms `NotifyIcon`, WinRT `Windows.Devices.Bluetooth*` / `Windows.Devices.Enumeration`, P/Invoke `hid.dll` + `cfgmgr32.dll`, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-16-r1-keeper-design.md`

## Global Constraints

- Bez administratora tiesībām, bez draiveru instalēšanas, bez Windows testa režīma.
- Programma drīkst pārot / noņemt pārošanu tikai ierīcei, kuras adrese ir saglabāta kā programmas pults. Nekad citai.
- Nekādu logu un fokusa pārņemšanas; tikai paziņojumu joslas baloni.
- Nosaukuma sākums pults atpazīšanai: `Magicsee R1`.
- Pārošana: `Pairing.Custom.PairAsync(DevicePairingKinds.ConfirmOnly, DevicePairingProtectionLevel.Default)`, programma pati izsauc `Accept()`. Katram mēģinājumam jauns `BluetoothLEDevice` objekts.
- Saskarnes teksti latviski, tieši kā šajā plānā.
- Dati: `%LOCALAPPDATA%\R1Keeper\` (`settings.json`, `r1keeper.log`).
- Visos projektos `<Nullable>enable</Nullable>`, `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`, `<NuGetAudit>false</NuGetAudit>` (privātā NuGet barotne nav sasniedzama un citādi dod brīdinājumus).
- Katrs commit beidzas ar rindu `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Komandas ir PowerShell, palaižamas no `f:\source\R1_remote`.

  ```csharp
  public readonly record struct PultAdvertisement(ulong Address, string LocalName);
  public interface IPultBluetooth {
      event Action<PultAdvertisement>? AdvertisementReceived;
      event Action<ulong>? LinkLost;                 // saite ar šo adresi pārtrūka

  }

      public KeeperState State { get; }

      public event Action<ulong>? PultLearned;

  }
  ```
  `FakeBluetooth` (testu projektā): lauki `Paired`, `Connected`, `UnpairResult = true`, `Queue<bool> PairResults` (tukša = `true`), `Exception? ThrowOnPair`, `Exception? ThrowOnStart`, `List<string> Calls` (ieraksti `"unpair"`, `"pair"`, `"watch"`), `TaskCompletionSource? PairGate` (ja iestatīts, `PairAsync` gaida to). `UnpairAsync` ar rezultātu `true` iestata `Paired = false; Connected = false`; `PairAsync` ar `true` iestata `Paired = true; Connected = true`. Metodes `RaiseAdvertisement`, `RaiseLinkLost`. Kopā ar to `InMemorySettingsStore` un `FakeClock` (`Now`, `Advance(TimeSpan)`).

**Noteikumi `HandleAdvertisementAsync` (šādā secībā):**
1. Ja `State == Paused` → neko.
2. Ja adrese ir iegaumēta un `adv.Address` nav tā → neko. Ja adrese nav iegaumēta un `adv.LocalName` nesākas ar `NamePrefix` (ordināls salīdzinājums) → neko.
3. Mēģināt paņemt slēdzeni bez gaidīšanas (`SemaphoreSlim.Wait(0)`); ja aizņemta → neko (sludinājums tiek atmests).
4. Ja adrese nav iegaumēta → iegaumēt, saglabāt iestatījumos, izsaukt `PultLearned`.
5. Ja `now() <` nākamā atļautā mēģinājuma laiks → neko.
6. `IsPairedAsync` (vienmēr prasīt, nekad neglabāt): ja sapārota → `State = Pairing`, `UnpairAsync`. Veiksme: beigt soli (pārošana notiks pie nākamā sludinājuma). Neveiksme: skat. 8.
7. Ja nav sapārota → `State = Pairing`, `PairAsync`. Veiksme: neveiksmju skaitītājs = 0, `WatchLink`, `State = Connected`.
8. Neveiksme (rezultāts `false` vai izņēmums): skaitītājs++, nākamais atļautais laiks = `now() + retry.DelayAfterFailure(skaitītājs)`, `State = Absent`, ieraksts žurnālā. Slēdzene vienmēr tiek atbrīvota.
